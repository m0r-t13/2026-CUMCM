# 2026 CUMCM 赛前准备

全国大学生数学建模竞赛的论文模板与代码工作目录。

## 目录

- `论文/`：LaTeX 论文源文件、模板样式、插图及示例 PDF；模板说明见 [论文/README.md](论文/README.md)。
- `代码/`：用于存放数据处理、建模与可视化代码，目前尚未添加程序。

## 论文入口

- 主文件：[论文/example.tex](论文/example.tex)
- PDF 示例：[论文/example.pdf](论文/example.pdf)
- 模板文件：`论文/cumcmthesis.cls`、`论文/cumcm2026.sty`

原模板来源及使用说明保留在 `论文/README.md` 中。
LaTeX 编译临时文件由 `论文/.gitignore` 排除。
