# 检测点输入与定位区域绘图

双击同目录下的 **启动检测点绘图.bat**，打开本地窗口。也可以运行：

```powershell
python -X utf8 检测点绘图.py
```

1. 填写检测点个数，支持 1～100 个。
2. 每行输入一个检测点的 `x y 示向度`，支持空格、逗号或制表符分隔。坐标单位是米；示向度单位是度，从正东方向起逆时针计量。
3. 误差半宽默认 1°，对应题目规定的 ±1°。
4. 点击 **绘图并检验**。
5. 切换 **定位区域放大图** 和 **检测点与测向角域总览**。
6. 点击 **导出当前图像（SVG）** 保存当前视图。SVG 是可放大、可编辑的矢量图，可用浏览器打开。

示例输入：点数填 2，坐标区填写：

```text
-1000 0 0
0 -1000 90
```

图中蓝色为定位多边形，红色线段为最远点连线，红色虚线圆为同直径圆，绿色实线圆为最小包围圆。V 为区域顶点，S 为检测点；灰色长虚线是示向度射线，灰色点线为误差角域边界。两个坐标轴采用相同长度比例，圆不会因坐标比例不同而变成椭圆。

窗口显示区域直径、两个圆的半径、最大超出距离及覆盖判定。出现圆外顶点时，放大图用红圈标出。图像基于附录 2 的角域交会模型，没有加入 1800 米目标圆域和接收距离圆盘约束。

若检测数据没有共同可行位置，会报告「交集为空」；若无法形成有界区域，会报告「交集无界」。此时只画检测射线，图框不会被误用为定位区域边界。

依赖与原程序相同：Python、NumPy、SciPy，另使用 Python 自带的 Tkinter 窗口组件。当前电脑的环境已具备这些依赖。请将 `检测点绘图.py`、`b1_coverage.py`、`launch_viewer.py` 与启动文件放在同一目录。

也可直接从已有 JSON 导出图像：

```powershell
python -X utf8 检测点绘图.py --input results/two_station_counterexample_input.json --svg results/四边形反例_放大图.svg
python -X utf8 检测点绘图.py --input results/two_station_counterexample_input.json --svg results/四边形反例_总览.svg --view overview
```
