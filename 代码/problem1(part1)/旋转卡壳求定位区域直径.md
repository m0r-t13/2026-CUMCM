> **问题 1 前半问**：已知若干检测点坐标及某干扰源关于这些检测点的示向度，给出采用交会定位法计算**多边形定位区域直径**的算法。

## 1. 先明确一个前提：直径不是"直接"能算的

题目给的是**角度**（检测点坐标 + 示向度），要求的是**长度的最大值**。中间必须先把角度信息还原成一个点集。所以前半问实际是四步：

```
角度 ──①──> 半平面 ──②──> 凸多边形 ──③──> 顶点对 ──④──> 最大值
      线性化          求交            离散化        组合优化
```

本文只展开 ③、④（旋转卡壳）；① 与 ② 的要点放在 §4，因为它们是 ③ 的输入前提。

## 2. 三个关键结论

### 定理 A（直径在顶点取到）

设 $K\subset\mathbb R^2$ 为紧凸集，$V_1,\dots,V_n$ 为其极点（多边形的顶点），则

$$D=\max_{P,Q\in K}\lVert P-Q\rVert=\max_{1\le p<q\le n}\lVert V_p-V_q\rVert .$$

**证明**：固定 $Q$，映射 $P\mapsto\lVert P-Q\rVert$ 是凸函数；凸函数在紧凸集上的最大值必在极点取到。对 $Q$ 同理。∎

**意义**：这一步把**不可数的连续优化**压成 $\binom n2$ 个数的比较。没有它，旋转卡壳无从谈起。

### 定理 B（直径端点必为对踵点对）

若一对顶点允许存在**平行的支撑线**，称其为**对踵点对（antipodal pair）**。直径必由某对踵点对取到。

**证明**：设 $A,B$ 达到直径 $D$。过 $A$、$B$ 分别作垂直于 $AB$ 的直线 $L_A,L_B$。若 $K$ 中某点 $P$ 落在 $L_A$ 外侧（即 $\angle PAB>90^\circ$），则 $\lVert PB\rVert^2=\lVert PA\rVert^2+\lVert AB\rVert^2-2\lVert PA\rVert\lVert AB\rVert\cos\angle PAB>\lVert AB\rVert^2=D^2$，与 $D$ 是直径矛盾。故 $K$ 全部位于 $L_A$ 内侧。同理 $L_B$。于是 $L_A\parallel L_B$ 是 $K$ 在 $A,B$ 处的平行支撑线，$A,B$ 为对踵点对。∎

**意义**：候选集从 $\binom n2$ 个顶点对缩到"对踵点对"。

### 引理 C（对踵点对只有 $O(n)$ 个）

**单调性**：设 $k(i)$ 为边 $(V_i,V_{i+1})$ 的对踵顶点（即到该边所在直线距离最大的顶点）。当 $i$ 沿逆时针递增时，$k(i)$ **单调不减**（模 $n$）。

**证明思路**：函数 $S_i(k)=\operatorname{area}(V_i,V_{i+1},V_k)$ 在凸多边形上关于 $k$ 单峰；当边绕多边形逆时针旋转一周，峰的位置也逆时针单调移动一周。∎

**推论**：全部对踵点对只有 $O(n)$ 个——具体地，每条形如 $(V_i,V_{k(i)})$ 或 $(V_{i+1},V_{k(i)})$，共 $2n$ 个（含重复）。**这正是"旋转卡壳"能 $O(n)$ 的根本原因**：卡尺绕多边形转一圈，对踵顶点只前进、不后退，全程推进次数 $\le 2n$。

实测（本实现）：

| 多边形类型 | $n$ | 对踵点对个数 | 顶点对总数 $\binom n2$ |
|---|---|---|---|
| 严格凸（无平行边） | 325 | **325**（$=n$） | 52650（**162 倍**） |
| 含平行边（矩形） | 4 | 6 $=3\lfloor n/2\rfloor$ | 6 |
| 含平行边（正六边形） | 6 | 9 $=3\lfloor n/2\rfloor$ | 15 |
| 严格凸（随机） | 400 例 | 恒等于 $n$ | — |

即：**严格凸时对踵点对恰为 $n$ 个；存在平行边时可增多，但不超过 $3\lfloor n/2\rfloor$，始终是 $O(n)$。**

## 3. 算法

### 3.1 伪代码

```
算法  旋转卡壳求凸多边形直径
输入: 逆时针、严格凸的顶点序列 P = (V_0, ..., V_{n-1})
输出: 直径 D 与达到直径的顶点对

1  若 n = 0        : 返回 (0, ∅)
2  若 n = 1        : 返回 (0, (0,0))
3  若 n = 2        : 返回 (|V_0 V_1|, (0,1))
4  k ← 1                                   // 初始对踵顶点
5  对 i = 0 .. n-1:
6      ni ← (i+1) mod n
7      循环:                                 // 推进对踵顶点，直至面积不再增大
8          nk ← (k+1) mod n
9          若 area2(V_i, V_ni, V_nk) > area2(V_i, V_ni, V_k):
10             k ← nk
11         否则: 跳出
12     用 (V_i, V_k) 与 (V_ni, V_k) 更新当前最优
13 返回 D 与最优顶点对
```

其中 `area2(a,b,c)` 是三角形面积的两倍（叉积）。因为输入是逆时针凸多边形，所有其他顶点都在每条有向边的左侧，故该值恒非负。

### 3.2 为什么第 7 行的循环不需要"回退"

边从 $(V_i,V_{i+1})$ 前进到 $(V_{i+1},V_{i+2})$ 时，边本身逆时针转了一个外角；由引理 C，最远顶点只会继续逆时针走。所以在整个第 5 行的循环里，`k` 单调前进，总推进次数不超过 $2n$。**内层循环虽然写在里面，但均摊到外层每一次迭代是 $O(1)$**，故总时间 $O(n)$。

### 3.3 正确性

1. 由定理 A，只需在顶点对中找最大距离；
2. 由定理 B，达到直径的那一对必为对踵点对；
3. 第 7–12 行枚举了 $(V_i,V_{k(i)})$ 与 $(V_{i+1},V_{k(i)})$ 对每个 $i$，覆盖全部对踵点对；
4. 故第 12–13 行取到的最大值就是直径。∎

### 3.4 复杂度

| 步骤 | 复杂度 |
|---|---|
| 求凸包（单调链） | $O(m\log m)$，$m$ 为候选点数 |
| 顶点净化 | $O(n^2)$ 最坏（迭代去共线），本题 $n$ 极小 |
| **旋转卡壳求直径** | $\mathbf{O(n)}$ |
| 对照：暴力枚举顶点对 | $O(n^2)$ |

## 4. 本题的完整流程（③④ 的输入从哪来）

```
示向度 (S_i, θ_i), 半角 α
   │
   │ ① 每个角楔 → 3 条半平面 a·x ≤ c
   │     两条边界射线所在直线 + 一条过顶点垂直于中轴的"前方"半平面
   │     （第三条不可省：只用两条会同时保留反向的对顶楔）
   ▼
3k 条半平面
   │
   │ ② 有界性判断：外法向按幅角排序后最大间隙 < π，否则区域无界、无有限直径
   │ ② 求交：顶点枚举法 —— 有界多胞体的顶点必为两条边界直线交点，
   │        枚举线对交点、保留可行者、求凸包（无需人为包围盒）
   ▼
逆时针严格凸多边形 V_1..V_n
   │
   │ ③④ 旋转卡壳 O(n)
   ▼
直径 D 与直径端点
```

**为什么必须先做 ②**：`k=1` 时区域本身就是无限角楔；若各示向度的方向锥存在公共方向（例如两个检测点测得相同示向度），交集同样无界。此时**必须把"无界"作为正常结果报告**，而不是让它算出一个错误的大数。

## 5. 实现要点与陷阱

### 5.1 输入必须是**逆时针**且**严格凸**

旋转卡壳依赖两条前提：

- **逆时针**：`area2` 恒非负，才能用"面积是否增大"判断对踵点推进方向。代码里 `rotate_to_ccw()` 用有向面积符号强制规范化。
- **严格凸（无三点共线）**：若存在共线顶点，同一条边方向会对应多个"最远顶点"，面积比较出现相等平台，推进逻辑会退化。`convex_hull()` 用 `cross <= 0` 弹出条件去掉共线点，保证输出严格凸。

### 5.2 顶点净化（本题特有，必须做）

角楔的两条边界直线，加上过顶点的法向直线，**三线共点于检测点 $S$**。于是顶点枚举时这三条线两两求交会给出**同一个点算三次**，产生若干仅相差 $10^{-13}$ m 的重合候选点。凸包不认它们是同一点（浮点不完全相等），会保留为顶点，形成 $10^{-14}$ m 量级的**极短边**。

后果不仅是"难看"：极短边会让以顶点为基准的几何量（如后半问要用的顶点张角）彻底失去意义。`simplify_polygon()` 按坐标量级的相对容差（默认 $10^{-9}$）合并近重合点与近共线点。实测中，不做净化会在随机实验中冒出十几个假结论。

### 5.3 守卫计数器

第 7 行的 `while` 理论上由单调性保证终止，但浮点误差可能造成"面积相等却不跳出"的假象。代码里加了 `advances <= 2n+4` 的守卫，越界即停——这是一个廉价的健壮性保险。

### 5.4 浮点比较用相对容差

面积比较用的是尺度相关的量（长度²），故 `antipodal_pairs()` 的等面积判定用 `tol = 1e-12 * scale²`；直径比较用 `1e-9 * D`。**不要**用绝对容差，否则坐标量级一变（本题从几十米到几千米）判断就会失效。

### 5.5 退化情形

| 输入 | 处理 |
|---|---|
| $n=0$ | 返回 $D=0$ |
| $n=1$ | 返回 $D=0$ |
| $n=2$（凸包退化成线段） | 返回两点距离 |
| 全部点共线 | 凸包自动退化为 2 点 |
| 大量重复点 | 凸包先去重 |

## 6. 验证

`python test_rotating_calipers.py` —— 全部通过：

| 编号 | 检验内容 | 结果 |
|---|---|---|
| T1 | 旋转卡壳 $O(n)$ vs 暴力 $O(n^2)$ | 1000 个随机凸多边形，**最大偏差 0.000e+00 m** |
| T2 | 直径端点必为对踵点对（定理 B） | 500 个多边形，例外 0 |
| T3 | 对踵点对个数 $\le 3n$（引理 C） | 400 个多边形全部满足，$c/n$ 恒为 1.000 |
| T4 | 对踵点对枚举 vs「平行支撑线」定义暴力法 | 8 个多边形，卡壳枚举的每一对都确为对踵点对 |
| T5 | 退化输入（$n=0/1/2$、共线、重复点） | 正确 |
| T6 | 平行边（矩形、正 24 边形） | 矩形 $D=10.770330$、正 24 边形 $D=200.000000$（理论值 200） |
| T7 | **端到端**：真源必须落在由精确示向度构造的区域内 | 200 个随机算例，违反 0 |

T4 的做法值得说明：它不依赖卡壳算法本身，而是按**定义**暴力枚举——对 20000 个方向 $d$，找使 $d\cdot P$ 最大与最小的顶点，其组合即为对踵点对。两种完全独立的途径结论一致。

T7 是最有价值的端到端检查：先指定真源 $G$，按几何算出精确示向度，则 $G$ **必须**落在构造出的定位区域内部。这一步能同时抓住角楔半平面符号写错、第三条半平面漏掉、求交方向搞反等一大批错误。

1. **区域顶点数 $n$ 远达不到上界 $2k$**（$k=12$ 时 $n=10$，上界 24）。因为一条新角楔只有在**确实切到当前区域**时才会新增顶点；否则它是**冗余约束**。
2. **增加检测点常常完全无效**：上表 11 次增量中有 **6 次 $D$ 的降幅恰好为 0**（$k=4\!\to\!5$、$7\!\to\!8$、$9\!\to\!10$、$11\!\to\!12$ 等）。这说明"多布一个站"并不自动等于"定位更准"——**必须看新站的角楔是否切到当前定位区域**。这一结论对问题 2（第二个检测点如何选）是直接的动机。

| 271 | 36585 | 271 | 0.292 | 7.023 | 24.1 |

**必须诚实说明**：本题定位区域的顶点数 $n\le 2k$（$k$ 为检测点数），实际是个位数。上表显示 **$n<32$ 时暴力枚举反而更快**（卡壳的常数更大）。所以：

> 旋转卡壳在本题中的价值**不在运行速度**，而在**定理层面**——它证明了"直径只需在 $O(n)$ 个对踵点对中寻找"，从而给出一个**可证明正确、且复杂度最优**的直径算法。
> 论文里如果写"我们用了高效的 $O(n)$ 算法"，评委会认为没抓住重点；正确的写法是"由定理 A、B 与引理 C，直径问题可归约为 $O(n)$ 个对踵点对的枚举，我们据此给出算法，并用 $O(n^2)$ 暴力枚举交叉校验"。

代码中两者**都实现了**：`rotating_calipers_diameter()` 为主，`brute_force_diameter()` 作对照，全部算例偏差为 0。
