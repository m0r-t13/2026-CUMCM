# 2026 CUMCM B题 问题3：机器狗自适应搜索、定位与清除程序

## 1. 项目简介

本程序用于 **2026 CUMCM B题问题3** 的机器狗自动搜索、定位与清除任务，仅针对题目中的 **全向干扰源** 场景。

程序的总体目标是：

1. 在圆形场地内搜索所有可能存在的干扰源频道；
2. 对已发现的干扰源维护一个始终包含真实位置的保守可行区域；
3. 利用多次测向不断缩小该可行区域；
4. 当能够保证干扰源位于清除半径内时，自动移动到安全清除点并执行 `/clear`；
5. 在保证搜索完整性的前提下，自适应调整搜索站位置，使搜索过程同时承担部分定位任务，从而降低后续额外移动和测量开销。

当前版本的核心改进是：

> **将固定“中心 + 六边形外圈”的7点搜索，改为带覆盖证书的自适应7站搜索。**

外圈搜索站允许向高价值定位位置偏移，但任何偏移都必须通过“剩余站数仍能完成1000 m全覆盖”的安全检查；若不能保证覆盖，则自动回退到原有六边形骨架。

# 4. 整体算法框架

程序分为两个主要阶段：

```text
进入模拟器
    │
    ▼
阶段A：自适应保证搜索
    │
    ├─ 搜索未知频道
    ├─ 建立干扰源可行区域
    ├─ 搜索站顺便进行二次/多次测向
    └─ 用覆盖证书判断是否已完成全场搜索
    │
    ▼
阶段B：主动定位与清除
    │
    ├─ 为尚未精确定位的源选择下一测点
    ├─ 更新可行区域
    ├─ 判断最小包围圆半径
    └─ 满足条件后执行清除
    │
    ▼
输出总结并退出
```

# 6. 干扰源状态表示

程序不会直接估计干扰源的单一坐标，而是为每个频道维护一个：

```python
SourceState
```

其中包含：

```text
channel
poly
observations
cleared
clear_attempts
```

最重要的是：

```text
poly
```

它表示当前所有观测条件下干扰源可能存在的 **保守可行多边形**。

设计目标始终是：

\[
G \in P
\]

其中：

- \(G\) 为真实干扰源位置；
- \(P\) 为程序当前维护的可行区域。

因此程序宁可使区域稍大，也不会主动排除真实位置。

# 7. 初始可行区域

场地是半径：

\[
R=1800\text{ m}
\]

的圆。

程序使用一个正180边外接多边形近似该圆：

```python
regular_circumscribed_polygon()
```

由于采用的是 **外接** 多边形，所以：

\[
\Omega_{\text{真实场地}}
\subseteq
P_0
\]

从而保持保守性。

# 8. 测向后的可行域更新

如果机器狗在位置：

\[
S
\]

测得方位：

\[
\theta
\]

测向误差为：

\[
\pm 1^\circ
\]

则真实目标方向一定处于：

\[
[\theta-1^\circ,\theta+1^\circ]
\]

形成的角域内。

程序通过：

```python
clip_wedge()
```

使用两个半平面对当前多边形进行裁剪。

得到：

\[
P'
=
P\cap W(S,\theta)
\]

其中 \(W\) 为测向角楔。

---

## 8.1 `direction` 的额外约束

当测量返回：

```text
direction
```

程序还利用两个距离信息：

### 距离大于5 m

因为如果距离小于等于5 m，应返回：

```text
near
```

因此 `direction` 意味着目标不在5 m近距范围内。

程序利用沿测向中心方向的线性投影约束进行保守裁剪。

### 距离不超过1500 m

因为收到有效方向意味着目标处于最大接收范围内，因此加入：

\[
d\le1500
\]

约束。

程序仍通过外接正多边形近似圆盘，以保证真实圆盘完全包含于允许区域。

---

# 9. `near` 情况

如果测量结果为：

```text
near
```

说明：

\[
d\le5\text{ m}
\]

程序会直接在当前位置对该频道调用：

```text
/clear
```

若清除成功，则将频道加入：

```text
cleared
```

集合。

# 10. 安全清除判据

程序不会简单使用“估计中心”执行清除，而是计算当前可行多边形的：

```text
Minimum Enclosing Circle
```

即最小包围圆。

记：

\[
P\subseteq B(C,r)
\]

如果：

\[
r\le19\text{ m}
\]

则由于：

\[
G\in P
\]

可保证：

\[
\|G-C\|\le19\text{ m}<20\text{ m}
\]

因此程序到最小包围圆圆心：

\[
C
\]

执行：

```text
/clear
```

可以保留约1 m安全裕量。

对应参数：

```python
CLEAR_R = 20.0
READY_RADIUS = 19.0
```

# 11. 阶段A：自适应7站保证搜索

## 11.1 原始保证骨架

程序仍保留一个完整的安全后备方案：

```text
中心 + 半径1200 m的正六边形外圈
```

即：

\[
S_0=(0,0)
\]

以及：

\[
S_k=
1200
\begin{bmatrix}
\cos(\phi+60^\circ k)\\
\sin(\phi+60^\circ k)
\end{bmatrix},
\quad k=0,\ldots,5
\]

完整7站能够保证场地内任意位置距离至少一个扫描站不超过1000 m。

---

## 11.2 第一个搜索站

第0站始终固定为：

```text
(0, 0)
```

程序在这里扫描所有尚未发现的频道。

如果已经发现题目允许的最大16个干扰源，则直接停止未知频道搜索。

# 12. 六边形旋转角选择

原点扫描完成后，程序会在：

```text
0°, 5°, 10°, ..., 55°
```

之间搜索六边形旋转角：

\[
\phi
\]

目标是使外圈搜索站尽量同时成为已经发现源的良好交会测向位置。

使用的几何指标近似为：

\[
U=
\frac{d_1d_2}{|\sin\gamma|}
\]

其中：

- \(d_1\)：目标到第一次测量站的距离；
- \(d_2\)：目标到候选站的距离；
- \(\gamma\)：两次观测方向的交会角。

当：

\[
\gamma\rightarrow0
\]

两条观测方向接近平行，定位效果较差。

因此程序倾向于选择：

- 基线更合适；
- 交会角更大；
- 距离条件更好的搜索站。

# 13. 自适应搜索站生成

每一轮搜索并不一定直接访问原六边形骨架点。

程序通过：

```python
_adaptive_source_candidates()
```

生成候选搜索站。

候选包括两类。

## 13.1 原始骨架点

所有尚未访问的六边形骨架点都会保留为安全候选。

---

## 13.2 面向定位的偏移点

程序选出当前可行区域直径最大的若干尚未完成源：

```python
ADAPTIVE_SOURCE_LIMIT = 4
```

对于每个源先调用：

```python
choose_next_measure_point()
```

求出该频道当前的理想主动定位位置：

\[
Q_i
\]

然后找到距离 \(Q_i\) 最近的两个剩余骨架站。

假设某骨架点为：

\[
B
\]

则生成：

\[
Q(t)
=
(1-t)B+tQ_i
\]

其中：

\[
t\in
\{0.05,0.10,0.15,0.20\}
\]

即骨架站分别朝理想定位位置偏移：

```text
5%
10%
15%
20%
```

只有满足：

- 位于场地内部；
- 对主频道保证可接收；
- 没有与已有测量点完全重合；

的候选才保留下来。

# 14. 覆盖证书

自适应搜索最关键的安全机制是：

```python
guaranteed_cover_radius()
```

程序计算：

\[
R_{\text{cover}}
=
\max_{G\in\Omega}
\min_i \|G-S_i\|
\]

其中：

- \(\Omega\) 为整个场地；
- \(S_i\) 为已经确定的搜索站。

只有：

\[
R_{\text{cover}}\le1000\text{ m}
\]

才能确认整个场地已经被保证接收区域覆盖。

---

## 14.1 覆盖半径的候选极值点

程序没有仅依赖网格采样，而是枚举最近站距离函数可能取得最大值的几何候选，包括：

1. 圆心；
2. 场地圆周上的轴向退化点；
3. 各站反方向对应的圆周候选点；
4. 两搜索站垂直平分线与场地边界圆的交点；
5. 三搜索站形成的外接圆圆心，即Voronoi顶点候选。

然后对每个候选计算：

\[
\min_i \|G-S_i\|
\]

取最大值作为覆盖半径。

---

# 15. 自适应候选的安全闸

一个自适应偏移点并不会因为定位效果好就直接采用。

程序还会调用：

```python
minimum_completion_subset()
```

检查：

> 如果现在访问这个候选点，在剩余的搜索站预算中，是否仍然存在一组原始骨架点，可以让最终整个场地达到1000 m覆盖？

假设已经访问 \(k\) 个站。

访问候选站后，剩余预算为：

\[
7-(k+1)
\]

程序从尚未访问的骨架点中枚举所有可能子集。

由于外圈骨架最多只有6点，组合数量最多：

\[
2^6=64
\]

因此可以直接穷举。

若不存在满足：

\[
R_{\text{cover}}\le1000
\]

的补点方案，则当前自适应候选直接被拒绝。

这一检查保证：

> 自适应偏移只能提高搜索与定位复用程度，不能破坏最多7站完成全场保证搜索的能力。

---

# 16. 自适应搜索站评分

通过覆盖安全检查后的候选会进行综合评分。

程序使用：

\[
Score=
N_{\text{remain}}\cdot1800
+
D_{\text{move}}
+
0.55R_{\text{cover}}
-
650G_{\text{loc}}
-
90N_{\text{joint}}
\]

其中：

### \(N_{\text{remain}}\)

当前候选访问以后，为完成全覆盖至少还需要补多少个原骨架站。

对应：

```python
ADAPTIVE_REMAINING_STATION_PENALTY = 1800.0
```

该项优先级最高。

---

### \(D_{\text{move}}\)

机器人当前位置到候选搜索站的移动距离。

程序倾向于减少额外移动。

---

### \(R_{\text{cover}}\)

访问该候选点以后，当前搜索站集合的覆盖半径。

权重：

```python
ADAPTIVE_COVER_RADIUS_WEIGHT = 0.55
```

覆盖半径越小越好。

---

### \(G_{\text{loc}}\)

该位置对主频道的预测定位收益。

定义为：

\[
G_{\text{loc}}
=
1-\frac{D'_{\text{pred}}}{D_{\text{current}}}
\]

其中：

- \(D_{\text{current}}\)：当前可行区域直径；
- \(D'_{\text{pred}}\)：在候选位置再测一次后的预测最坏直径。

奖励系数：

```python
ADAPTIVE_LOCALIZE_BONUS = 650.0
```

---

### \(N_{\text{joint}}\)

该位置还可以保证接收并可能顺便测向的其他源数量。

奖励：

```python
ADAPTIVE_JOINT_BONUS = 90.0
```

---

最终选择：

\[
\boxed{\arg\min Score}
\]

作为下一搜索站。

---

# 17. 搜索站的实际执行

到达某个自适应搜索站以后，程序依次执行：

```text
1. 扫描所有仍未知的频道
2. 记录该位置为已访问搜索站
3. 如果该站是为某个主频道偏移出来的：
      对该频道执行主测向
4. 检查其他已知源
5. 对值得顺路测向的源继续测量
6. 如果某源已经达到清除条件且清除点很近，则直接清除
```

因此阶段A并不只是“搜索未知源”，而是：

\[
\boxed{\text{搜索 + 定位复用}}
\]

---

# 18. 何时结束搜索阶段

存在两种提前结束条件。

## 18.1 已发现16个源

如果：

```text
found_count >= 16
```

由于题目允许的源数量已经达到上限，剩余频道可直接判为空频道。

---

## 18.2 覆盖证书完成

如果：

\[
R_{\text{cover}}\le1000\text{ m}
\]

则说明整个场地内任意位置至少距离一个已经扫描过的搜索站不超过1000 m。

此时仍未发现的频道可以判空。

程序会输出：

```text
覆盖证书完成
```

以及最终覆盖半径。

# 19. 搜索阶段的顺路定位

对于已经发现但尚未精确定位的频道，程序会检查当前搜索站是否：

1. 与已有测量位置不同；
2. 能保证接收到该频道；
3. 能显著缩小当前定位区域。

若满足：

\[
D'_{\text{pred}}
\le
0.78D_{\text{current}}
\]

则在当前位置顺便再次测向。

对应参数：

```python
STATION_PROBE_IMPROVEMENT = 0.78
```

即期望一次测向至少把预测直径缩小到原来的78%左右。

对于只有一次观测的源，程序会更积极地利用第二个测向站。

# 20. 阶段B：主动定位

搜索结束后，所有存在的频道已经被发现。

对于尚未达到清除条件的源，程序调用：

```python
choose_next_measure_point()
```

选择下一主动测向位置。

整体流程：

```text
构造保证接收候选区域
        │
        ▼
粗网格搜索
        │
        ▼
几何指标 U 粗筛
        │
        ▼
预测最坏直径精筛
        │
        ▼
局部细网格
        │
        ▼
再次精筛
        │
        ▼
选择近优集合中移动距离较小的位置
```

# 21. 保证接收条件

候选测点 \(Q\) 必须满足：

\[
\max_{G\in P}\|Q-G\|\le1000
\]

由于 \(P\) 为凸多边形，距离最大值可以通过多边形顶点检查。

对应函数：

```python
robust_receive()
```

这样可以保证：

> 无论真实源实际位于当前可行域中的哪个位置，去该测点都能处于1000 m保证接收范围内。

---

# 22. 主动定位粗筛指标

程序使用：

\[
U=
\frac{d_1d_2}{|\sin\gamma|}
\]

作为几何粗筛指标。

其中：

- \(d_1\)：目标到参考测量站距离；
- \(d_2\)：目标到候选站距离；
- \(\gamma\)：两站相对于目标形成的夹角。

为了考虑目标位置未知，程序会从当前可行多边形中抽取若干：

- 顶点；
- 中心；
- 边中点；

计算最坏几何指标。

---

# 23. 预测最坏定位直径

对候选测点 \(Q\)，函数：

```python
predicted_worst_diameter()
```

从当前可行区域抽取多个可能真实位置 \(G\)。

对于每个 \(G\)：

1. 计算从 \(Q\) 看向 \(G\) 的真实方位；
2. 模拟测量中心误差：

\[
-1^\circ,\quad0^\circ,\quad+1^\circ
\]

3. 对当前可行区域进行模拟角域裁剪；
4. 计算裁剪后的多边形直径；
5. 对所有采样情况取最大值。

得到：

\[
D_{\text{pred}}(Q)
\]

程序倾向于选择：

\[
D_{\text{pred}}(Q)
\]

较小的测点。

该指标主要用于 **测点选择**，不会取代真实测量后的保守区域更新。

# 24. 粗网格与精网格

当前主动定位使用两级网格。

## 粗搜索

```python
COARSE_STEP = 125.0
```

首先对大范围候选区域进行搜索。

通过几何评分后保留：

```python
GEOM_KEEP_RATIO = 0.35
```

约35%的候选进入昂贵预测。

---

## 精搜索

在粗搜索最佳点附近继续使用：

```python
FINE_STEP = 30.0
```

的局部网格进行精化。

---

# 25. 近优集合

精确预测后，不一定直接选择预测值绝对最小的点。

程序接受：

\[
D(Q)
\le
1.15D_{\min}
\]

的近优候选。

对应：

```python
NEAR_OPT_RATIO = 1.15
```

然后从近优集合中选择距离机器人当前位置更近的点。

这样可以在：

```text
定位质量
```

与：

```text
移动成本
```

之间做一定折中。

---

# 26. 最小主动测向基线

程序优先要求新测点与已有观测点至少相距：

\[
80\text{ m}
\]

对应：

```python
MIN_ACTIVE_BASELINE = 80.0
```

目的是减少同一地点附近重复测向带来的低信息增益。

如果候选空间过窄，程序会放宽这一启发式限制，但仍避免完全重复同一点。

---

# 27. 多频道任务顺序

阶段B中，程序会对所有尚未清除频道计算下一目标位置。

如果源已经达到：

\[
r_{\text{MEC}}\le19
\]

则目标位置为其MEC圆心。

否则目标位置为主动定位函数给出的下一测点。

当前版本按照：

\[
\text{机器人当前位置到任务位置的距离}
\]

排序，优先执行最近任务。

因此当前自适应版本的主要创新集中在 **阶段A搜索站自适应化**，阶段B仍采用较简单的最近任务调度。

# 34. 当前算法的优势

### 1. 搜索完整性优先

任何自适应偏移都必须通过覆盖完成性检查，不允许为了定位收益破坏未知源搜索保证。

### 2. 搜索站能够复用为定位站

相比固定7点搜索，搜索移动本身可以产生更多有价值的第二次、第三次测向。

### 3. 定位区域始终保守

真实测量后的区域更新与候选测点预测相互独立。

即使某个启发式选点不是最优，也不会直接破坏：

\[
G\in P
\]

这一核心安全性质。

### 4. 清除具有几何保证

只有最小包围圆半径达到安全阈值才执行远距离清除。

### 5. 网络层具有幂等重试意识

同一动作重试复用 `request_id`，降低重复动作风险。

# 35. 当前版本的局限

当前版本仍然存在一些值得继续研究的部分。

## 35.1 阶段A和阶段B仍然分离

虽然阶段A已经能够顺带定位，但整体结构仍然是：

```text
先完成保证搜索
再进入主动定位
```

尚未真正实现搜索、定位、清除的完全统一规划。

---

## 35.2 自适应评分含经验权重

以下参数属于启发式权重：

```python
ADAPTIVE_REMAINING_STATION_PENALTY = 1800.0
ADAPTIVE_COVER_RADIUS_WEIGHT = 0.55
ADAPTIVE_LOCALIZE_BONUS = 650.0
ADAPTIVE_JOINT_BONUS = 90.0
```

它们用于平衡：

```text
覆盖安全
移动距离
定位收益
多频道复用
```

但目前不是直接根据模拟器真实虚拟时间成本推导得到的。

---

## 35.3 预测最坏直径使用有限采样

`predicted_worst_diameter()` 并未遍历连续可行域中的所有真实位置和所有误差值。

其主要作用是：

```text
候选测点之间的启发式比较
```

而不是严格证明一次测量后的理论最坏区域。

---

## 35.4 阶段B任务调度仍较简单

当前主动定位阶段优先处理：

```text
距离当前位置最近的下一任务
```

尚未同时考虑：

- 多频道共用测点；
- 完整路线；
- 测量成本；
- 切换频道成本；
- 清除顺路程度。

---

# 36. 推荐的后续优化方向

如果继续优化，建议优先考虑：

```text
1. 从模拟器虚拟时间规则建立真实动作成本模型
2. 将搜索、定位、清除统一成一个动态任务规划问题
3. 用真实收益/成本替代经验评分权重
4. 让一个主动测点同时服务多个频道
5. 对多频道任务进行路径联合规划
6. 根据演练日志统计真实移动、测量、换频道、清除耗时
```

最终可以将当前：

```text
覆盖规划
+
单源定位规划
+
顺路测向
+
最近任务调度
```

统一为：

\[
\boxed{
\text{在保证所有源最终被发现和安全清除的条件下，最小化总虚拟时间}
}
\]

# 39. 总结

当前程序的核心思想可以概括为：

\[
\boxed{
\text{保证搜索}
+
\text{保守集合定位}
+
\text{自适应搜索站复用}
+
\text{主动测向}
+
\text{MEC安全清除}
}
\]

其中最重要的设计原则是：

> **自适应只能优化效率，不能破坏搜索完整性和定位保守性。**

因此原始7点骨架始终作为安全后备方案，而自适应搜索站只有在能够证明剩余站数仍足以完成1000 m全覆盖时才会被采用。

这一版本相比固定7点搜索，主要优化目标不是强行减少搜索站数量，而是：

\[
\boxed{
\text{让每一次搜索移动尽可能同时产生定位价值}
}
\]

从而减少后续阶段为了定位干扰源所需要的额外移动与测量。
